# Bundled IBM Plex fonts

These Latin-subset fonts preserve FlipOS typography without a build-time Google Fonts request. They are distributed under the SIL Open Font License 1.1 in `OFL.txt`.

| File | Font | Style and weights |
| --- | --- | --- |
| `ibm-plex-sans-latin-variable.woff2` | IBM Plex Sans | Normal, variable 100–700 |
| `ibm-plex-mono-latin-500.woff2` | IBM Plex Mono | Normal, 500 |
| `ibm-plex-mono-latin-600.woff2` | IBM Plex Mono | Normal, 600 |
| `ibm-plex-mono-latin-700.woff2` | IBM Plex Mono | Normal, 700 |

Sources: [IBM Plex upstream](https://github.com/IBM/plex), [Sans CSS](https://fonts.googleapis.com/css2?family=IBM+Plex+Sans:wght@400;500;600;700&display=swap), and [Mono CSS](https://fonts.googleapis.com/css2?family=IBM+Plex+Mono:wght@500;600;700&display=swap).

The WOFF2 files came from the `fonts.gstatic.com` URLs in those official Google Fonts stylesheets. Each file was validated with FontTools before inclusion.
